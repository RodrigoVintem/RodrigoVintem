## Rodrigo Vintém

MSc Computer Science student at [Instituto Superior Técnico](https://tecnico.ulisboa.pt), Lisbon.
I like building things that have to work under pressure: distributed protocols, game engines, and computer vision on messy real-world data.

- **3rd place at Junction Lisbon 2026** (~150 participants) with [ShelfOS](https://github.com/franciscogfsm/ShelfOS): stock and planogram checks from fixed ceiling cameras. [Live demo](https://shelfos-demo.vercel.app)
- **Contributor to [PokéRogue](https://github.com/pagefaultgames/pokerogue)** (5.9k ★), an open-source browser roguelite, as my bachelor's final project
- **Engine work on [Cubos](https://github.com/GameDevTecnico/cubos)**, a C++ voxel engine built by the GameDev Técnico club
